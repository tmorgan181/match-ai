**match.ai v2 Feature Sheet**
*(Build ONLY after validating MVP with 50+ survey completions and 10+ successful matches)*

---

### Survey Enhancements
- [ ] Long mode: domain tags + skills + collaboration preferences
- [ ] Adaptive questioning (skip irrelevant questions based on prior answers)
- [ ] Multi-language support (Spanish to start)
- [ ] Accessibility audit + screen reader optimization
- [ ] "Save progress" option for long mode
- [ ] Question randomization to reduce order effects

### Matching System
- [ ] Automated matching algorithm (complementary archetypes + shared domains)
- [ ] Match scoring/ranking (not just binary yes/no)
- [ ] Batch matching runs (weekly instead of continuous manual review)
- [ ] "Match preferences" settings (local only, async only, etc.)
- [ ] Mutual opt-in before intro (both people confirm interest)
- [ ] Optional demographics survey

### Communication & Follow-up
- [ ] Templated intro emails via Resend
- [ ] Follow-up surveys: "Did you connect? Start a project?"
- [ ] Success story collection (with permission)
- [ ] Monthly digest: "X new people matched this month"
- [ ] Unsubscribe/pause matching option

### Educational Content
- [ ] Curated resource links per archetype on result page
- [ ] "Learn more" sections for each domain
- [ ] Blog/articles about AI ethics topics
- [ ] Case studies of successful collaborations

### Feedback & Quality
- [ ] 5-star survey rating system
- [ ] Open feedback form
- [ ] "Report a problem" option
- [ ] Analytics dashboard: completion rates, drop-off points, archetype distribution

### Anti-Abuse & Security
- [ ] reCAPTCHA v3 (add only if bot submissions become a problem)
- [ ] Rate limiting on survey submissions
- [ ] Email verification before entering match pool
- [ ] GDPR export/delete tools
- [ ] Abuse reporting for matched users

### Expansion
- [ ] Additional domains beyond chatbots/mental health
- [ ] "Projects" board where people can post specific collaboration asks
- [ ] Discord/Slack integration for matched users
- [ ] API for researchers studying AI ethics communities
- [ ] Archetype badges/share graphics for social media

### Platform Evolution
- [ ] User accounts (optional, for managing match status)
- [ ] In-platform messaging (alternative to email intros)
- [ ] Calendar integration for scheduling intro calls
- [ ] Paid tier with Claude API debrief upgrade
- [ ] Mobile app
